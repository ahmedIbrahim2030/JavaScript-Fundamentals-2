# JavaScript Fundamentals – Part 2

This project is a small JavaScript practice exercise focused on core programming concepts in JavaScript. It includes examples and experiments covering control flow, functions, arrays, objects, loops, and while statements.

## Project Overview

The app is a simple static webpage with an embedded script file. It demonstrates fundamental JavaScript topics often taught in beginner-to-intermediate JavaScript courses.

## Files

- `index.html` – The page structure and page styling.
- `script.js` – JavaScript examples and practice code.

## Topics Covered

- Conditional statements (`if/else`)
- Function declarations and expressions
- Arrow functions
- Arrays and array methods
- Objects and object methods
- For loops and while loops
- Random number generation and loop control

## How to Run

1. Open the project folder in your browser or a local web server.
2. Open `index.html` in a browser.
3. Open the browser console to see the JavaScript outputs.

## Notes

This project is designed as a learning exercise rather than a production app. It is useful for reviewing JavaScript basics and experimenting with code snippets directly in the browser.
